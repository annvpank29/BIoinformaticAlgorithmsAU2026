## Ответы на вопросы

**1. Чем Gibbs Sampler отличается от Profile-most probable k-mer?**

Profile-most probable k-mer выбирает k-мер с наибольшей вероятностью по профилю. Gibbs Sampler выбирает k-мер случайно: чем выше его вероятность, тем больше шанс, что он будет выбран.

**2. Почему текущий мотив удаляется при построении профиля?**

Чтобы профиль строился по остальным последовательностям, без учёта текущего мотива. Так выбранная последовательность не влияет сама на себя, и алгоритм может подобрать для неё более подходящий k-мер.
